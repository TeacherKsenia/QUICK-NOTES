HOW IT WORKS

Simple, local and under your control

01
Web demo

Try everything in the browser. Its data can disappear if browser site data is cleared, so export a backup if the notes matter.

02
Desktop app

The desktop version keeps its working data locally on your computer and remains usable without accounts or foreign cloud storage.

03
Moving notes

Click a note to edit it. Use its three-dot menu for Move to… or Delete; both actions stay close to the note without adding extra icons.

04
Deleting groups and categories

Open the profile menu to edit or delete a group. Categories are managed in Settings; notes can be moved elsewhere or deleted with the category.

05
Backups

Use Export backup before clearing browser data or moving to another computer. Restore backup returns that saved copy.
